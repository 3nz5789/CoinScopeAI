**Scope:** Only the unresolved questions whose answers Phase 1 needs to *exit* — across MARKET, ICP, POSITIONING, BRAND, PRODUCT, TRUST, RISK *(BRAND added 2026-05-04 via Path B charter amendment)*.

**Convention:** each question carries an ID matching its workstream prefix (M / I / P / B / Pr / Tr / R), a *blocking* deliverable, the data needed to answer, an owner, and a target answer-by date. A question is closed by either an answer or an explicit defer (with a phase pointer).

## How to use this register

- A question stays `OPEN` until it has either an answer (recorded inline + reflected in the relevant scaffold doc) or an explicit defer (with a phase pointer, e.g., "deferred to Phase 2 charter — needs cohort exit memo").
- Every question that *gets answered* should produce a downstream patch: a Decision Register row moves to `LOCKED`, and the relevant scaffold (`01–06`) is updated.
- Questions that turn out to *not* matter (e.g., MQ-4 if cohort interviews show no false-positive category) should be marked `MOOT` with one-line reason — do not delete.
- New questions that emerge during Phase 1 work are added here, not to the workstream scaffolds, so the scaffolds stay decision-ready.
